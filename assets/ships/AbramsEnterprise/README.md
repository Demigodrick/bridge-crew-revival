# Enterprise (Kelvin timeline)

Select **ENTERPRISE (KELVIN)** in the briefing room (scroll the ship box down), or set `[Ships] PlayerShip = AbramsEnterprise`.
Uses the game's Aegis bridge and systems; no new bridge interior or combat balance changes.

Model: USS Enterprise NCC-1701, Star Trek (2009), version 6, by **Ricky "MadMan1701A" Wallace** (MadShipyard).
Source: https://trekmeshes.eu/download/dl231/USSEnterpriseNCC1701Abrams
Original author notes: `CREDITS.txt`.
Converted for the mod by YannikB98 (tools in `tools/kelvin` of the mod's repository).

The contributor YannikB98 confirmed permission to include the model and textures on 2026-11-13. This records that confirmation; it does not relicense the model under the code's license. The original author notes refer to personal use. Star Trek marks belong to their respective owners.

The ship uses the Aegis's own Bussard collectors (meshes, materials and animation), taken from the installed game at runtime. No extracted game assets are included.

Name and registry follow the crew's settings. The saucer and both nacelles use Michroma Regular, an approximation of the Kelvin lettering, in plain black. Michroma is by Vernon Adams / the Michroma Project Authors under the SIL Open Font License; see `Michroma-OFL.txt`. `Michroma-atlas.bin` and `Michroma-glyphs.txt` are a rendering of it (167 uppercase/Latin-1 characters; others show `?`). The texture files stay as they are: the lettering is painted in memory.

Textures are at most 2048 pixels on a side and a multiple of four on each, so they compress and load quickly.
